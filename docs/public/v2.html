Why Constraints Matter

Most frameworks give you maximum flexibility. Pulse does the opposite. Constraints aren't limitations — they're guarantees:

  • One spec per page No split files. No hidden conventions. Everything co-located.
  • Pure mutations State changes are synchronous, side-effect-free, testable.
  • Validation at startup Malformed specs fail before shipping. No runtime surprises.
  • CSRF automatic Form submissions protected by default. No opt-out.
  • Constraints enforced min/max bounds on state are guaranteed. State cannot violate them.
